# 📊 AI Financial Assistant

An advanced AI-powered financial analysis platform that helps investors, traders, and analysts make smarter decisions. The assistant provides real-time data insights across stocks, crypto, and forex markets, combined with AI-driven analytics for financial health, risk assessment, and market sentiment.

# 🚀 Features

# 📈 Interactive Heatmaps

Stock Market Heatmap (Top Gainers/Losers, Sectors, Market Cap)

Cryptocurrency Heatmap (Price, Volume, Market Trends)

Forex Heatmap (Currency Pair Strength & Movements)

# 🤖 AI-Powered Insights

**Powered by Google Gemini AI**

- **Comprehensive Stock Analysis**: Real AI-powered analysis with technical and fundamental insights
- **Geopolitical Risk Assessment**: AI analysis of geopolitical factors affecting stocks
- **News Analysis**: Real-time news aggregation and sentiment analysis from multiple sources
- **Social Media Sentiment**: AI-powered sentiment analysis across Twitter, Reddit, and StockTwits
- **Investment Recommendations**: Intelligent buy/hold/sell recommendations with confidence scores
- **Risk Analysis**: Detailed risk factor identification and assessment
- **Market Outlook**: AI-generated short-term and long-term market predictions

**Setup Required**: See [API_SETUP.md](./API_SETUP.md) for API key configuration

# 📊 Market Data Integration

Live charts powered by TradingView

Customizable dashboards for Stocks, Crypto, and Forex

Support for multiple timeframes (1D, 1W, 1M, etc.)

# ⚡ Modern UI/UX

Intuitive grid-based layout

Responsive design for desktop and mobile

Dark/Light mode support

# 🔧 Setup & Installation

1. Clone the repository
2. Install dependencies: `npm install`
3. Configure API keys (see [API_SETUP.md](./API_SETUP.md))
4. Run development server: `npm run dev`

## API Keys Required

- **Google Gemini API** (Required for AI analysis) - Get from [Google AI Studio](https://makersuite.google.com/app/apikey)
- **Alpha Vantage API** (Optional, has default) - Get from [Alpha Vantage](https://www.alphavantage.co/support/#api-key)
- **NewsAPI** (Optional) - Get from [NewsAPI](https://newsapi.org/register)

See [API_SETUP.md](./API_SETUP.md) for detailed setup instructions.
